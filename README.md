One joke about office life, one line, under 200 characters — an entry for the
[Make the AI Judge Laugh](https://make.fun/bounty/u-alfasurya91-make-the-ai-judge-laugh-6ed40225)
bounty on make.fun.

> Our 9 a.m. standup runs forty minutes every day, and nobody has stood up once.

`main.ts` writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
Run it with `node main.ts`.
